# RAG-Challenge-2 学习导读

> 用 **分治（Divide & Conquer）** 的方式，把一个 RAG 比赛冠军方案拆成 22 章逐个击破。

本导读面向 [RAG-Challenge-2](https://github.com/IlyaRice/RAG-Challenge-2) —— RAG Challenge 比赛双料冠军的源码。系统需要回答关于公司年报 PDF 的自动生成问题，获奖技术组合为：

- Docling 自定义 PDF 解析
- 向量检索 + **父文档检索**（Parent Document Retrieval）
- **LLM 重排**提升上下文相关性
- 思维链（CoT）+ 结构化输出提示
- 多公司**比较题路由**

## 分治地图

把整个系统当作一棵递归分解的树，每章攻克一个节点：

```text
RAG 问答系统（回答年报问题）
├── 全局篇      全景地图 + 跑通最小闭环          第 1~2 章
├── 摄入篇      PDF → 结构化文本                第 3~5 章
├── 索引篇      文本 → 向量库                    第 6~8 章
├── 检索篇      问题 → 相关上下文                第 9~12 章
├── 生成篇      上下文 → 结构化答案              第 13~18 章
├── 编排篇      配置、CLI、实验矩阵              第 19~20 章
└── 评测篇      误差分析 → 消融迭代              第 21~22 章
```

学习策略：第 1 章建立全局地图 → 自顶向下逐分支深入 → 每章末尾的**合并问题**检验该子问题如何回归父问题。

## 如何使用本导读

| 你想… | 建议路径 |
|---|---|
| 快速了解全貌 | 第 1 章即可（约 30 分钟） |
| 动手跑起来 | 第 2 章，用 `data/test_set`（5 份年报）练手 |
| 深入核心竞争力 | 第 6、9、10、11 章（索引 + 检索，本项目命名的主角） |
| 学 LLM 工程细节 | 第 13~18 章（prompt、schema、并发、比较题） |
| 做自己的 RAG 项目 | 全部走完后做第 22 章毕业项目 |

每章包含：

- **本章目标** —— 一句话说清攻克哪个分治节点
- **源码导读** —— 关键文件、行号、设计取舍
- **动手任务** —— 都能用 `data/test_set` 低成本完成
- **自测 / 合并问题** —— 检验子问题的解如何"合并"回父问题
