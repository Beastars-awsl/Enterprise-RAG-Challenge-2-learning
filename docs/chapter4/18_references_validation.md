# 第 18 章 引用、校验与提交格式

> **本章目标**：理解 `relevant_pages` 的语义、引用去重的集合语义、页码校验
> 与比赛提交文件的组装。
> 分治策略：把"可信"拆成 **模型自报引用 + 系统侧校验 + 格式合规** 三个子问题。

## 18.1 引用字段与提取

五族模板的 `AnswerSchema` 都要求 `relevant_pages`：只包含直接支撑答案的页
（直接答案页、强支撑页），至少一页。模型自报引用是"可验证性"的来源，
也是比赛评分项。

`src/questions_processing.py` 的 `_extract_references`（第 143 行）：
从答案 dict 提取页码，查报告 JSON 确认该页存在；`_validate_page_references`
（第 172 行）过滤越界/不存在的页码——**宁缺毋滥**：坏引用比少引用更伤分
（引用质量也是评分项）。

## 18.2 去重与提交组装

- `_create_answer_detail_ref`（第 302 行）：组装
  (pdf_sha1, page_index) 元组——提交格式要求的引用单元
- 不同公司可能引用同一 (pdf_sha1, page_index)（比如两家子公司共用一份报告），
  按元组去重、保留首见顺序——**提交引用是集合语义，重复只会放大噪音**

提交文件由 `process_all_questions`（第 709 行）组装，
参数即提交元信息（team_email / submission_name / pipeline_details）。
同一实验的不同次运行输出不互相覆盖（追加 `_NN` 编号）。
